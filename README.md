# Ideal Gas Infinity Quiz

Individual practice on enthalpy and internal-energy changes of an ideal gas between two states. Students compute Δh and Δu by two methods and compare them.

## Live tool

[Open Ideal Gas Infinity Quiz](https://nuhaaljuneidi.github.io/ideal-gas-infinity-quiz/)

## Features

- Each student is assigned an official case from their ERAU email; the case is restored if they return.
- After submitting the assigned case, students continue with unlimited practice cases.
- Guest access for practice without an ERAU address.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
